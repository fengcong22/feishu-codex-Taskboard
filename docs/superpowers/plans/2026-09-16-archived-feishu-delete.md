# 归档飞书任务删除修复

目标：用户确认后可永久删除已归档且空闲的任务；旧事件重放不会重新建单或启动剪辑。

原因：`deleteArchivedTask` 为保留飞书事件唯一占位，直接拒绝全部可信飞书任务；界面仍展示删除按钮。

设计：在同一 SQLite 事务内保存事件 ID、身份摘要和删除时间，再删除任务与级联记录。保留无外键依赖的最小删除记录，不保留任务正文、评论或配置。创建入口及数据库插入触发器拒绝已删除事件；受认证且身份一致的登记请求返回 HTTP 410 / `FEISHU_TASK_DELETED`，身份不同返回冲突。Bridge 仅在登记调用遇到这组状态和错误码时，将事件持久化为 succeeded/ignored，其他错误继续按原重试策略处理。新 event_id 不受影响。
