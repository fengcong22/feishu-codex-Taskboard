# 配置页稳定布局与历史配置读取修复

目标：修复四页切换导致外围分区跳动，支持手动调整目录区宽度，统一运行配置的停用入口，保留并正确显示服务器已保存的 Auto-Cut 包。

约束：保留所有现有工作树改动、真实数据库和包注册文件；不修改阶段事件、回写、Auto-Cut-Lite 协议或自动执行开关；不清空配置，不通过复制示例覆盖历史配置。布局尺寸属于浏览器偏好，不属于学科运行配置。

- [ ] 布局：显式设置顶部工具栏行与剩余内容行；目录和设置独立滚动。加入可聚焦的垂直分隔条，支持指针、左右键、Home/End 调整，范围受容器宽度约束；记住宽度。窄屏保留纵向布局。

- [ ] 包读取：确认真实注册文件及本机 API 数据完整；包管理区明确区分加载中、读取失败与真正空列表，支持重新读取，失败时保留已加载的数据和编辑；学科包下拉采用同样规则并随包变更刷新。验证文件跨服务重建仍保持完整。
- [ ] 验证：组件行为测试、包持久化/API 测试、生命周期测试、类型检查与构建；只读比较配置哈希。复核改动后在本机加载新版本，运行 check-local.ps1。
