# 飞书学科配置四页布局设计

## 目标

将正式学科配置页面从一页连续表单改为四个可切换的功能页面，解决阶段编辑器和回写规则在狭窄区域内拥挤的问题。页面改造只调整信息架构与显示，不改变飞书字段、保存请求、Auto-Cut-Lite manifest、任务快照或 Bridge/Taskboard 协议。

## 页面结构

同一个学科仍使用一个草稿表单和一个保存动作。四个页签仅控制当前显示的面板，编辑状态保留在父组件中；切换页签、切换后再返回均不丢失未保存内容。切换到另一学科时默认回到“基础与执行”。

| 页签 | 内容 |
| --- | --- |
| 基础与执行 | 剪辑模式、本机自动执行状态、Auto-Cut 包、ZIP 获取方式、上传入队方式、来源目录与上传并发；旧单阶段的触发设置也在这里。 |
| 素材与阶段 | 状态字段、素材文档字段、命名字段，以及初稿、初审修改、终审修改各自的视频、意见、音频、命名后缀配置。 |
| 存储与目录 | 固定课程目录开关、总路径、课程名称字段、ZIP 上传与各阶段目录；“指定状态进入时创建 00成片”合并到这里。 |
| 飞书回写 | 课程目录文本字段回写，以及三个阶段的处理中和 ZIP 上传成功后的已有单选字段/选项回写。未启用固定课程目录时，显示前置条件提示，不显示依赖的回写控件。 |

## 交互与无障碍

页签采用标准 `tablist`、`tab`、`tabpanel` 语义，支持鼠标、方向键、Home、End 和焦点移动。每次只挂载当前面板，避免视觉上成为一个长页面；保存条继续在表单底部，保存时提交全部四页的草稿状态。

## 布局与视觉

配置页以其实际内容区域作为响应式容器。字段网格和阶段素材来源用自适应列，空间不足时自动变为单列；回写阶段卡以至少 260px 的最小列宽自动换行。阶段编辑器把进入触发独占一行，视频和意见来源按两列排列，音频和可选路径占全宽。继续采用冷白背景、蓝色主操作、绿色成功、琥珀草稿、红色错误，以及 8px 单层卡片。

## 兼容性边界

- 保留 `SubjectForm`、`saveDraft()` 的 patch 结构、字段 ID/选项 ID 和已有草稿数据。
- 不删除数据库中的全局流程标签配置、旧学科配置或任何历史记录；全局流程标签编辑器已从普通页面移除。
- 不改变 Auto-Cut-Lite 单 ZIP 运行约束，亦不改变飞书事件筛选、任务路由、凭据、端口或启动方式。

## 验收

1. 默认打开“基础与执行”，四个页签均可访问并且同一时间只显示一个面板。
2. `00成片` 仅在“存储与目录”；阶段状态回写和课程路径文本回写仅在“飞书回写”。
3. 三个阶段的独立素材来源仍可编辑，切换页签后草稿值保留，保存请求仍提交原有 `stages` 和 `delivery` 数据。
4. 400px 左右的窄配置区域不横向挤压阶段或回写卡片，字段自动排列为单列。
5. 组件测试、类型检查和生产 Web 构建通过；启动检查继续确认服务仅绑定本机 loopback。
